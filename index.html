Selected Work

Clinical Trials: Outcome & Duration Prediction

Core contributor

Built phase-level pipelines for trial outcome prediction (TOP benchmark) and duration regression, fine-tuning BioBERT and BioMistral (7B) with full fine-tuning and LoRA on multi-GPU DDP. Showed that probing frozen encoders matches or exceeds full fine-tuning at a fraction of the trainable parameters, with both outperforming the prior state of the art (HINT) across Phase I–III. Mentored two interns to delivery.

Immunology: TCR–pMHC Interface Scoring

Core contributor

Repurposed AlphaFold2 Multimer as a conformational ensemble generator to expose interface uncertainty that ipTM misses. Built a multi-tool interface scoring pipeline (ModFOLDdock2, VoroMQA, GNINA, Arpeggio) and used stability selection and SHAP to distil thousands of features into a compact set of robust affinity predictors.

DeepChain: Protein Prediction Apps

Owned end-to-end

Led development and deployment of protein prediction applications on InstaDeep’s DeepChain platform (signal peptide and enzyme class prediction), containerised with Docker and run on GCP and AIchor.

Bio Skills for Claude Code

Created & led

Sole author of a multi-agent toolkit that turns natural-language questions into bioinformatics tool calls: custom subagents, agent-to-agent orchestration, Claude Code hooks and plugins, and provenance-tracked pipelines across 22 data sources. In internal use at InstaDeep.
